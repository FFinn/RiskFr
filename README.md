## Результат оценки

Исходная версия — `4903ad261d30bc2d1171e455f916e445a7963b4e` [учебного репозитория](https://devsecops.gitlab.yandexcloud.net/devsecops-projects/unit-9-final-practice). По результатам проверки **SQL-инъекция не обнаружена**: значения передаются отдельно от текста SQL. Два предупреждения Semgrep относятся к подстановке внутреннего номера параметра и признаны ложными срабатываниями.

Проверками функций подтверждены подмена пользователя, списание сверх остатка при одновременных переводах и повторное списание после отказа Redis.

Исходные `app/*.py`, `requirements.txt` и `docker-compose.yml` сохранены без изменений. Исправление импортов вынесено в [отдельный файл](security/patches/launch-imports.patch) и применяется только к копии приложения внутри учебного образа. `compose.check.yml` поднимает эту копию с отдельной базой. Её `app/main.py` побайтно совпадает с файлом, на котором выполнены 47 HTTP-запросов: SQL-инъекция не подтвердилась, подмена пользователя воспроизведена. SQL-запросы и проверка личности не менялись.

После отделения правки импортов образ собран заново и все 47 запросов повторены. Результаты совпали с первой проверкой; новый журнал сохранён отдельно.

Дополнительный запуск Semgrep с готовыми наборами `p/python` и `p/sql-injection` проверил семь исходных файлов: 151 правило Python, срабатываний и ошибок нет. Подтверждённые ручными проверками ошибки личности и денежных операций сохраняют свой статус.

## Запуск учебного стенда

```bash
umask 077
if [ ! -f .assessment.env ]; then
  printf 'ASSESSMENT_DB_PASSWORD=%s\n' "$(openssl rand -hex 24)" > .assessment.env
fi
docker compose --env-file .assessment.env -p riskfr-http \
  -f compose.check.yml up -d --build --wait api
```

Описание запросов: [http://localhost:18081/docs](http://localhost:18081/docs). Порядок испытаний и удаления учебной базы приведён в [инструкции](security/REPRODUCE.md).

## Как открыть модель

В настольном OWASP Threat Dragon 2.6.2 открыть `security/model/riskfr.json`, затем диаграмму «Переводы и история операций». При выборе элемента доступны связанные угрозы. Всего в модели **18 угроз: 17 открытых, одна снижена существующей параметризацией SQL**.

[PDF](security/reports/threat-dragon-report.pdf) выгружен из Threat Dragon кнопкой `PDF Report`: семь страниц, диаграмма и все 18 угроз.
