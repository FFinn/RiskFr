## Автоматические задания GitLab

В [запуске для версии a0df3e3](https://devsecops.gitlab.yandexcloud.net/s2417991/riskfr/-/pipelines/16146) обнаружены ошибки стандартных автоматических заданий:

- [Сборка](https://devsecops.gitlab.yandexcloud.net/s2417991/riskfr/-/jobs/66727): превышено время ожидания загрузки образа `auto-build-image` из внешнего реестра.
- [Испытания](https://devsecops.gitlab.yandexcloud.net/s2417991/riskfr/-/jobs/66728): выбранное средство сборки Python не поддерживает предложенный режим запуска испытаний.
- [Проверка качества](https://devsecops.gitlab.yandexcloud.net/s2417991/riskfr/-/jobs/66729): отказ при загрузке образа `codeclimate/codeclimate-structure`.

Последующие задания этого запуска пропущены. Успешное выполнение автоматических проверок GitLab **не подтверждено**. Отчёт Semgrep получен отдельным запуском, журнал поведения — проверкой на изолированной базе.
