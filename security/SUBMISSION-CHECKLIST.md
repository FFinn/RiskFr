## Оговорки для приёмки

1. **SQL-инъекция.** В исследованной версии значения передаются параметрами. Приложено заключение с разбором всех SQL-вызовов. Для выполнения требования о положительной находке нужна другая исходная версия либо уточнение задания у куратора.
2. **Происхождение PDF.** Документ подготовлен из сформированной страницы отчёта Threat Dragon: диаграмма и сведения об угрозах выгружены из приложения, подписи переведены, таблицы преобразованы в карточки. Это не неизменённая штатная печать браузера. Редактируемая модель приложена и позволяет сформировать штатный отчёт повторно.
3. **Границы подтверждения.** Проверки денежных сценариев выполнены вызовами функций на отдельной базе. Успешная эксплуатация через HTTP и фактический импорт в действующий DefectDojo не заявляются. Ошибки запуска исходного приложения не исправлялись.

## Автоматические задания GitLab

В [запуске для версии a0df3e3](https://devsecops.gitlab.yandexcloud.net/s2417991/riskfr/-/pipelines/16146) обнаружены ошибки стандартных автоматических заданий:

- [Сборка](https://devsecops.gitlab.yandexcloud.net/s2417991/riskfr/-/jobs/66727): превышено время ожидания загрузки образа `auto-build-image` из внешнего реестра.
- [Испытания](https://devsecops.gitlab.yandexcloud.net/s2417991/riskfr/-/jobs/66728): выбранное средство сборки Python не поддерживает предложенный режим запуска испытаний.
- [Проверка качества](https://devsecops.gitlab.yandexcloud.net/s2417991/riskfr/-/jobs/66729): отказ при загрузке образа `codeclimate/codeclimate-structure`.

Последующие задания этого запуска пропущены. Успешное выполнение автоматических проверок GitLab **не подтверждено**. Приложенный отчёт Semgrep получен отдельным запуском, а журнал поведения — проверкой на изолированной базе; эти результаты нельзя приписывать указанным заданиям GitLab. Изменение стандартного процесса сборки не входило в оценку и не выполнялось.

## Доступность материалов

Материалы находятся в ветке `main` проекта [RiskFr в GitLab](https://devsecops.gitlab.yandexcloud.net/s2417991/riskfr). Доступность опубликованной версии проверяется получением отдельной копии непосредственно из GitLab и сверкой содержимого файлов с подготовленным комплектом. Проект закрытый: чтение требует учётной записи с правами на проект. Наличие прав у конкретного куратора из проверки под учётной записью владельца не следует.
